An image-based CAPTCHA system built as the practical output of my diploma thesis at Univerzita Pardubice. The thesis researched non-text CAPTCHA approaches (rotation, object segmentation, upright-position detection) and resulted in two CAPTCHA implementations — one of which became RoCAPTCHA, publicly available via API for use in third-party web apps.

Released as a Django form widget, a standalone PHP library, and a MyBB forum plugin.
